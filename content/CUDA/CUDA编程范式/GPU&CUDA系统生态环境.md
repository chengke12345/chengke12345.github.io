# 1. GPU&CUDA系统生态环境

![image.png](1%20GPU&CUDA%E7%B3%BB%E7%BB%9F%E7%94%9F%E6%80%81%E7%8E%AF%E5%A2%83/image.png)

GPU 系统并不是独立存在的，它必须依赖于 CPU 系统环境。GPU 是硬件，软件，开发环境，和支持库的一个集合。

最底层是 CPU 和 GPU 硬件，GPU 是一个大规模并行计算的处理器。在这两个硬件基础之上，构建了驱动以及操作系统。在 OS/Driver 之上，有一个叫 CUDA 的并行开发环境，以及相关的并行计算的内容。这些内容构成了并行计算和数值计算的一套复杂的生态环境。通过这套生态环境，最终支持应用。 

目前 CPU 系统的发展已经遇到了各种各样的瓶颈，在2010左右，主频已经基本不怎么增加了。所以现在出现的多核系统和并行系统越来越多。多核和并行系统，是为了解决单核系统不能实现高性能，采用的折衷方案。这样背景下，应运而生，就产生了 「GPU 系统，Graphics Processing Unit」。

GPU 一开始是专门为了处理图形图像而设计的。但是后来应用到通用计算之后，展现出了很强的并行处理能力。在各种高性能计算场合，获得了很强的性能。

**特别注意**

1. 我们实际使用 CPU 和 GPU 时，大多数时候并不是在做计算，而是在做一些事务性的工作，这与我们直觉的理解有一定的出入。
2.  GPU，Graphics Processing Unit, 图形处理单元。一开始的确是为了处理图形图像数据，而专门设计的处理器架构。但是，后来应用在通用计算上之后，展现出极强的并行处理能力。后来把应用于大规模通用并行计算的单元，称为GPGPU, General Purpose Graphics Processing Unit.
3.  Graphics Processing Unit，在如今的语境下，已经不仅仅指的是图形图像的数据处理，它更多的泛指一切矩阵乘加这一类的计算任务。
